# MoonJQ CLI

These tests exercise the local `moonbit-community/jq` command-line surface. Run them
from its module directory so mooncram builds the checked-out implementation:

```sh
cd cmd/jq
moonx moonbit-community/mooncram@0.1.0 test ../../tests/cram/cli.md
```

The default backend is Wasm; add `--target native` to test the native backend.
Input files live in `fixtures/`, relative to this document. Pipeline helpers
use pinned tools from the Mooncakes `cli` account.

## File Input

```mooncram moonbit-community/jq
$ moonx moonbit-community/jq -c '.items[]' fixtures/data.json
1
2
3
```

```mooncram moonbit-community/jq
$ moonx moonbit-community/jq -r '.name' fixtures/data.json
Moon
```

## Stdin And Null Input

```mooncram moonbit-community/jq
$ moonx cli/printf@0.2.1 '{"nested":{"ok":true}}' | moonx moonbit-community/jq '.nested'
{
  "ok": true
}
```

```mooncram moonbit-community/jq
$ moonx cli/printf@0.2.1 '{"nested":{"ok":true}}' | moonx moonbit-community/jq -c '.nested'
{"ok":true}
```

```mooncram moonbit-community/jq
$ moonx moonbit-community/jq -n -c '{ok: true, values: [1, 2]}'
{"ok":true,"values":[1,2]}
```

## Multiple Inputs

```mooncram moonbit-community/jq
$ moonx cli/printf@0.2.1 '%s' '{"name":"Lin"}' | moonx moonbit-community/jq -r '.name' fixtures/a.json - fixtures/b.json
Ada
Lin
Grace
```

## Argument Parsing

Short flags can be combined, and options accept attached values. `--` lets a
filter begin with a hyphen.

```mooncram moonbit-community/jq
$ moonx moonbit-community/jq -nrc '"Moon"'
Moon

$ moonx moonbit-community/jq --raw-output --from-file=fixtures/filter.jq fixtures/users.json
Ada

$ moonx moonbit-community/jq -c -- '-length' fixtures/data.json
-3

$ moonx moonbit-community/jq
[2]

$ moonx moonbit-community/jq --from-file
[2]

$ moonx moonbit-community/jq -f fixtures/filter.jq -f fixtures/filter.jq fixtures/users.json
[2]
```

Help is generated by `moonbitlang/core/argparse` and exits successfully.

```mooncram moonbit-community/jq
$ moonx moonbit-community/jq --help
@STDOUT
Usage: jq [options] [args...]

Run jq filters over JSON input.

Arguments:
  args...  <filter> [file...]

Options:
  -h, --help                   Show help information.
  -c, --compact-output         Print compact JSON instead of pretty JSON.
  -l, --logs                   Treat input as newline-delimited JSON logs.
  -n, --null-input             Run the filter once with null input.
  -r, --raw-output             Print strings without JSON quotes.
  -f, --from-file <from-file>  Read the filter from FILE.
@STDERR (empty)
```
